## 三、逐页面原型交互说明（核心）

### 页面1：登录页

**页面用途**：后台管理员账号登录

**页面元素**

- 系统Logo \+ 系统名称：智能推销外呼系统

- 输入框：账号、密码

- 登录按钮、重置按钮

- 底部版权信息

**交互规则**

- 账号密码非空校验

- 登录失败弹窗提示：账号错误/密码错误/账号禁用

- 登录成功跳转【工作台】

- 未登录状态拦截所有后台页面

### 页面2：工作台（数据总览页）

**页面用途**：整体外呼业务数据概览，快速查看今日/累计外呼情况

**顶部筛选栏**：时间维度（今日/昨日/近7天/近30天/自定义时间）

**数据卡片（顶部4块）**

- 累计外呼总量

- 接通量 \& 接通率

- 有效意向客户数 \& 意向率

- 今日进行中任务数

**图表模块**

- 外呼趋势折线图：每日拨打、接通数据走势

- 客户意向分布饼图：高意向/观望/无意向/无效占比

**底部列表**：最近5条外呼任务快捷记录（可点击跳转详情）

### 页面3：外呼任务列表页

**页面用途**：所有外呼任务的管控、启停、查看、复盘

**顶部功能区**

- 搜索：任务名称

- 筛选：任务状态、话术场景、创建时间

- 按钮：【创建任务】【刷新】【批量导出】

**列表字段**

任务ID、任务名称、关联话术场景、总号码数、已拨打数、接通数、意向数、任务状态、创建时间、操作

**任务状态枚举**：待执行、执行中、已暂停、已完成、已终止、异常失败

**操作列（根据状态动态显示）**

- 待执行：启动、编辑、删除

- 执行中：暂停、终止、查看详情

- 已暂停：启动、终止

- 已完成/异常：查看详情、导出数据

### 页面4：创建外呼任务页（核心表单页）

**页面用途**：新建阿里云智能外呼推销任务

**表单模块1：基础信息**

- 任务名称（必填）

- 选择AI话术场景（下拉绑定已创建的阿里云Script场景）

- 外呼模式：自动外呼 / 预测外呼

**表单模块2：拨打规则配置**

- 允许外呼时间段（开始时间\-结束时间）

- 未接通重试次数（0\-3次可选）

- 单号码拨打间隔（秒）

**表单模块3：选择外呼号码资源**

- 方式1：选择已有号码分组

- 方式2：现场Excel导入号码（支持下载模板、上传、自动去重、黑名单过滤）

**底部按钮**：保存草稿、立即创建任务、返回列表

**创建成功交互**：弹窗提示成功，自动跳转任务列表，任务进入「待执行」状态

### 页面5：任务详情页

**页面用途**：单任务全量数据查看、单条通话复盘

**顶部任务概览卡片**：任务状态、总数量、已呼、接通、意向、接通率、意向率

**下方明细列表字段**

客户手机号（脱敏中间4位\*）、客户姓名、来源渠道、呼叫状态、通话时长、客户意向标签、通话录音、对话转写文本、拨打时间、操作

**列表操作**：查看对话、播放录音、下载录音、标记跟进、加入黑名单

### 页面6：号码库列表页

**页面用途**：管理所有待外呼客户资源

**顶部功能**：导入号码、新增单个号码、批量删除、批量加入黑名单、刷新、搜索

**列表字段**

脱敏手机号、客户姓名、备注、来源渠道、外呼状态、最近拨打时间、意向标签、创建时间、操作

**支持筛选**：未拨打、已拨打、已接通、有意向、无意向

**交互逻辑**：已加入黑名单号码自动置灰，不可选中外呼

### 页面7：黑名单管理页

**页面用途**：防骚扰合规管控，杜绝重复拨打拒接用户

**顶部功能**：手动添加黑名单、批量导入黑名单、移除黑名单、清空

**列表字段**：手机号、拉黑原因、拉黑时间、操作人、操作（移出黑名单）

**核心规则**：所有外呼任务自动跳过黑名单号码，无需人工过滤

### 页面8：AI话术场景管理页

**页面用途**：绑定阿里云外呼话术脚本，管理推销对话场景

**列表字段**：场景名称、阿里云InstanceId、ScriptId、状态、创建时间、操作

**操作功能**：新增场景、编辑话术、启用/禁用、查看录音、删除

**新增/编辑弹窗字段**

- 场景名称

- 阿里云实例ID

- 阿里云脚本ID

- 开场推销话术

- 常见问答配置（key关键词\-answer回答）

- 结束语

### 页面9：通话记录与复盘页

**页面用途**：全量通话数据复盘、质检、回访

**筛选条件**：时间范围、任务名称、意向等级、是否接通

**列表核心字段**

手机号、拨打时间、通话时长、接通状态、意向标签、完整对话文本、录音播放/下载

**弹窗详情**：点击查看对话，弹出层展示**完整人机对话上下文**，区分机器人话术、客户语音文字

### 页面10：数据报表中心

**页面用途**：推销业务数据统计、效果复盘、数据导出

**统计维度**：日/周/月/自定义时间段

**报表内容**

- 外呼总体指标统计

- 接通率、有效率、意向转化率统计

- 各话术场景转化效果对比

- 无效呼叫类型统计（空号/停机/拒接/无人接听）

**功能**：在线预览、Excel导出报表

### 页面11：阿里云接口配置页（系统核心配置）

**页面用途**：统一配置阿里云对接参数，全局生效

**配置表单字段**

- 阿里云AccessKey ID

- 阿里云AccessKey Secret

- 外呼主号码

- 回调地址（HTTPS）

- 接口超时时间、重试次数

**核心交互**：保存后自动校验阿里云接口连通性，提示「配置成功/接口连接失败」

### 页面12：账号权限 \& 操作日志页

**权限管理**：新增账号、分配角色（超级管理员/运营/只读）、启用禁用、改密

**操作日志**：记录所有关键操作（登录、创建任务、导入号码、修改配置、删除数据），包含操作人、IP、时间、操作内容，不可删除，永久留存

## 四、全局弹窗交互规则

### 4\.1 通用确认弹窗

删除、终止任务、清空数据等高危操作统一弹窗：**确认要执行该操作吗？操作不可撤回**

### 4\.2 导入弹窗

支持下载模板、拖拽上传、进度展示、上传结果提示（成功数、重复数、黑名单过滤数、失败数）

### 4\.3 录音播放弹窗

弹窗内嵌入音频播放器、显示通话时长、拨打时间、对话文本，支持边看文字边听录音

## 五、页面跳转逻辑图（文字版）

登录页 → 工作台 → 新建任务 → 导入号码 → 启动任务 → 实时任务列表查看进度 → 任务结束后查看详情/通话记录 → 数据报表复盘

## 六、空状态 \& 异常状态规范

- 无任务：暂无外呼任务，展示【立即创建任务】引导按钮

- 无号码数据：暂无客户号码，展示【导入号码】引导

- 无通话记录：暂无外呼通话数据

- 接口异常：页面提示「数据加载失败，请稍后重试」\+ 刷新按钮
